# 盯盘神经（场外基金）

全市场场外开放式基金的**持仓法净值估算终端**：用最新季报前十大重仓股 × 个股真实涨跌幅，
估算当日净值变化，并与官方公布净值逐日对比成 K 线。所有数据来自公开真实接口，**不模拟、不插值**，
缺数据如实留空并标注原因。

> 仅供个人非商业研究学习，非投资建议。数据版权归原作者/发布机构所有。详见 [LICENSE](LICENSE)。

## 功能

- **首页全市场列表**（约 2.5 万只）：单位净值、官方涨幅、今日估算、1日偏离、1月偏离、规模(亿)、费率、
  近1月/近3月/近1年；类型（股票/混合/指数/QDII/债券/FOF）× 主题（港股/美股/科创/半导体/医药…17 类）× 搜索 × 排序 × 分页
- **偏离口径 = 官方 − 估算**：正数表示官方高于估算（估算偏保守），负数表示估算偏高。
  1月偏离为近 1 个自然月内**双方都有数据的同一批交易日**各自复利后相减，悬停标注参与天数
- **自选 ☆ 与自定义分类**：自由新建/重命名/删除（可撤销），分组联动底部类目总规模；
  本地版存于本机 `userdata.json`，网页版存于当前浏览器 localStorage
- **点击基金弹层**：预测 K 线（开=昨官方净值，收=昨官方×(1+估算涨幅)）× 官方净值线 × 累计估算虚线 ×
  偏差柱副图；30/60/120/250 日切换、拖拽缩放、十字线悬停明细；前十大重仓股实时涨跌与贡献 pp；季度规模走势
- **规模与费率**：规模=季报披露期末净资产（悬停显示截止日）；费率=申购优惠最低档，悬停展开原价/管理费/托管费/销售服务费
- **底部类目总规模**：按当前筛选渐进聚合（季报口径，未披露只数如实标注）

## 本地运行（推荐，数据最全）

1. 安装 [Node.js](https://nodejs.org/) LTS（若已安装可跳过）
2. 双击 `启动.bat`：自动探测 node 安装位置、启动零依赖数据桥（仅监听 `127.0.0.1:8788`）、约 2 秒后自动打开浏览器
3. 黑窗口即数据服务进程，**勿关**；关闭即停止服务

无需 `npm install`：服务端仅用 Node 内置模块，前端为单文件 `index.html`（canvas 自绘图表）。

## 架构

```
index.html（单文件前端，file:// 或 http 均可）
   │ fetch JSON
   ▼
server.js（零依赖本地桥，127.0.0.1:8788）
   │ 代请求 + 聚合 + 重试/备用主机轮换 + 磁盘缓存 data_cache/ + inflight 去重 + 并发闸 6
   ▼
东财排行/移动接口/pingzhongdata/f10费率 · 腾讯行情与日K（A股/港股/美股专用端点） · 新浪A股备用
```

- 港/美股历史 K 线走腾讯 `hkfqkline` / `usfqkline` 专用端点（通用端点对非 A 股返回拦截页）
- 美股与基金净值日按**同日**对齐（实证偏差最小）；缺口日留空并以昨官方净值重新锚定
- 缓存 TTL：排行 30min、行情 60s、日K 20min、持仓/净值历史 12h、基础/费率 7d

## 网页版

线上地址：<https://dpsjcw-uf1u9pp1ptn.qoder.website>
**访问范围：私有** —— 需用站点所有者的 Qoder 账号登录后才能打开（匿名访问返回 401 登录页）。

部署于 Qoder Sites：静态前端 `dist/index.html` + 一个 Edge Function 数据桥（Deno 运行时）。

```
浏览器（同源）
   │ /functions/v1/app/<接口>
   ▼
functions/index.ts → functions/handler.ts（server.js 的同口径移植）
   │ fetch + 重试/备用主机轮换 + 内存缓存（TTL 同本地）+ inflight 去重 + 并发闸 6
   ▼
东财排行/移动接口/pingzhongdata/f10费率 · 腾讯行情与日K · 新浪A股备用
```

与本地版的差异（均为口径诚实处理，非功能缩水）：

- 边缘运行时不能落盘：磁盘缓存改为**模块级内存缓存**，冷启动首次拉取全市场列表约需十几秒
- 底部类目总规模改用**季报快照即时汇总**（`functions/scale_snapshot.json`，由本地真实缓存的
  东财 `FundMNBasicInformation` 期末净资产汇总而成，含 `generatedAt` 汇总日期，界面底部如实标注）；
  单只基金的规模/净值/行情/费率仍为真实请求
- 自选与自定义分类存于**当前浏览器 localStorage**（键 `dpsj_user_v1`），不上传服务器；
  分组筛选时由前端把分组代码随请求提交给云函数
- 估算/偏离按小块（12 只 / 6 只）分批请求，避免边缘单次请求超时，先到先显示

重新构建网页产物：`cp index.html dist/index.html`（前端为单文件，无构建步骤）。
快照如需更新：在本地跑一段时间积累 `data_cache/basic_*.json` 后重新汇总生成。

## 口径与局限（诚实声明）

- 估算仅覆盖前十大持仓（覆盖率逐基金标注），未覆盖其余持仓/债券/汇率/调仓，偏差属固有局限
- 交易所与基金披露为盘后/T-1 口径，免费源不存在盘中"实时份额/实时官方净值"
- 季报持仓为快照，调仓滞后是偏差主要来源；FOF/纯债持仓基金不适用持仓法，界面如实提示
- 所有数值均为真实接口返回或按上述公式由真实输入计算，**无随机/模拟/插值填充**
